This file records version-selection decisions for the MATLAB codebase under
`D:/NYU-USC/Cross-Processing/`, to be resolved before / during the Python port.

consolidation, has the 5-method taxonomy that matches the paper, and contains
the final ASCII tables documenting PDP-threshold, omni-synthesis, and AS-formula
combinations.

Deltas v1 → v7:
- v1→v2: switched from `PDP_NYU` cached PDP to raw H; used 3GPP instead of Fleury.
- v2→v3: restructured for MLX; added USC-Fleury path.
- v3→v4: implemented `noise_i + 5 dB` lower bound + `peak − 25 dB` rule; doc'd `circ_std`.
- v4→v5: added pure-NYU path with linear interpolation; explicit A–F scenarios.
- v5→v6: narrowed to Omni-synthesis × PDP-threshold study (6 combos).
- v6→v7: combined everything into 5 canonical methods (M1–M5) mapping to paper terminology.

## 8. MPC-peak vs full-PDP for USC AS

USC has two code paths for "AS":
- `USCprocessing.m:105-115` — Uses `Power_per_antenna = sum(db2pow(PDP_dir), 1)`
  on the **original un-thresholded** PDP, feeds into `ASfleury`.
- v7 M2 mirrors this (minus Fleury → 3GPP where needed).

The USC GT CSV was however generated by `NYU_Directional_5.m` using
per-PDP 25 dB threshold + `circ_std`. This is why M1 (not M2) matches GT.
Keep this distinction in the Python port; provide both.

## 9. Antenna pattern duplicates

- `NYU/4.TCSL/AntennaPattern/*.DAT` — original NYU 142 GHz 27 dBi horn.
- `USC/Codes4Reference/NYU_Code_Milcom/THz_3D_pattern_aver.mat` — USC 3-D horn.
- `ProcessingUSC145GHzData/{aziCut,elevCut}.mat` — 2-D cuts of the 3-D pattern.
- `NYU/NYU_Data/aziCut.mat` — **ambiguous filename** (7 GHz cut, not 145). Use
  `ProcessingUSC145GHzData/aziCut.mat` for USC 145 GHz; use `NYU/NYU_Data/aziCut.mat`
  only as a stand-in for NYU 7 GHz until the authoritative `7_phi{0,90}_pd.mat`
  files are loaded.

## 10. Noise-floor estimator naming

Two implementations coexist:

- Inline definition in `USC142GHz_Method_Comparison_Full.m:1090` — may differ.

Port both and unit-test for equivalence before discarding.
